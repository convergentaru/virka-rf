# Вирка.РФ — робототехническая платформа для кровель

Публичная страница проекта: https://convergentaru.github.io/virka-rf/

«Вирка.РФ» — проект разработки робототехнической платформы для автоматизированного обследования, диагностики и восстановления плоских кровель с применением компьютерного зрения, автономной навигации и технологий повторного использования материалов.

## Текущий статус

Сайт представляет инженерную концепцию и направление разработки. Он не заявляет о наличии готового прототипа, завершённых испытаний, патентов или подтверждённых технико-экономических характеристик. Полная автоматизация ремонтных операций — целевая задача разработки.

## Структура

- `index.html` — адаптивная одностраничная презентация проекта.
- Вёрстка, стили и небольшие эффекты интерфейса находятся в одном файле.
- Сайт статический: сборка и серверная часть не требуются.

## Публикация

Репозиторий `convergentaru/virka-rf`, ветка `main`, корень репозитория. Для GitHub Pages выберите **Deploy from a branch → main → /(root)**.
